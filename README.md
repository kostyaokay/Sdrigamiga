# Лабораторная 10: Угрозы и модели безопасности

## Найденная уязвимость: Insecure Data Storage (M9)
**Описание:** Данные дневника сохраняются в файл `notes.json` в открытом виде без шифрования.
**Вектор атаки:** Злоумышленник с Root-правами или доступом к файловой системе может прочитать личные записи.
**Контрмера:** Использовать EncryptedSharedPreferences или AES-256.
